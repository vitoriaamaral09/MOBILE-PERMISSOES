# MyLocationApp (Expo)

App React Native com persistência de dados e permissões:
- AsyncStorage: salva preferência de tema (dark/light)
- expo-location: captura localização atual com permissão
- expo-sqlite: salva e recupera localizações

## Como rodar
```bash
npm install
npx expo install expo-location expo-sqlite @react-native-async-storage/async-storage
npm start
```
